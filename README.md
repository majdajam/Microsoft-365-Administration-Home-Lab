# Microsoft 365 Administration Home Lab

## Overview

This project was completed using a Microsoft 365 Business tenant to gain hands-on experience with cloud-based user administration and support tasks. I created and managed users, groups, licenses, and email services while practicing common Help Desk responsibilities in a Microsoft 365 environment.

The goal of this lab was to gain practical experience supporting users with account management, access issues, password resets, MFA configuration, and basic cloud administration.

---

# Technologies Used

- Microsoft 365 Admin Center
- Microsoft Entra ID
- Exchange Online
- Outlook Web App
- Microsoft Authenticator

---
# What I Configured

- Created Microsoft 365 user accounts and assigned available licenses.
- Created groups and organized users based on department roles.
- Managed Exchange Online mailboxes and verified email access.
- Reset passwords and assisted with account recovery scenarios.
- Configured and enforced multi-factor authentication (MFA) using Microsoft Authenticator.
- Reviewed user sign-in information to troubleshoot authentication issues.

---

# What I Tested

- User account creation and management.
- Login, authentication, and access troubleshooting.
- Password reset workflow.
- MFA enrollment and verification.
- Mailbox access and email functionality.

---

# What I Learned

- How Microsoft 365 manages cloud users, groups, and identities.
- How Microsoft Entra ID handles authentication and access control.
- How Exchange Online provides cloud-based email services.
- Common Help Desk tasks involved in supporting Microsoft 365 users.
- Differences between cloud identity management and traditional on-premises environments.

---

# Skills Practiced

- Microsoft 365 Administration
- Entra ID User Management
- Exchange Online Administration
- Identity and Access Management (IAM)
- MFA Support
- User Account Troubleshooting
- Cloud Administration Basics
